# MARKETHON — AI Marketing Automation Platform

Intelligent marketing automation platform powered by AI decision engines, lead scoring, omnichannel routing, interactive operations, and animated dashboards.

## 🚀 Getting Started & Local Development

The modern, fully-animated web application is built with **React**, **Vite**, **TanStack Router / Start**, **Tailwind CSS**, and **Framer Motion** inside the `joy-hug-machine-main/` directory.

### Quick Start (from project root)

```bash
# Install dependencies (first time only)
cd joy-hug-machine-main && npm install && cd ..

# Launch the animated local development server
npm run dev
```

The application will be live at:
👉 **http://localhost:5173/**

### Development Scripts

- `npm run dev`: Starts the animated Vite dev server on port 5173.
- `npm run build`: Compiles production build with optimizations.
- `npm run preview`: Previews production build locally.

## ✨ Key Features & Animations

- **Hero Shader Background**: Dynamic animated galaxy background with twinkling stars and mouse parallax.
- **Framer Motion Visuals**: 3D interactive spring tilt cards, evaporating vapor particle heading loop, and scroll reveals.
- **AI Operations Room**: Joystick-controlled navigation controller with 8 dedicated route experiences.
- **Interactive Timeline Roadmap**: Multi-step animated milestone journey with rich micro-interactions.
- **Omnichannel Automation Pipelines**: Highlighting automated lead intake from WhatsApp, Instagram, Meta Ads, and Google Ads.
